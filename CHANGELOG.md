# Changelog

| Version | Date       | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 0.2.0   | 2026-10-28 | Guided setup page: a five-step stepper (credentials, sign in, number, test, incoming) that opens one step at a time and auto-advances, then a Ready summary with Change links, test send, activity and opt-outs. New options `backUrl`/`backLabel` (back link, `back` in status) and `loginUrl` (302 for an unauthorized page load); new `sms.verifyConnection()` (false when the login is refused or GoTo is unreachable). Blank and `CHANGEME` option/env values count as unset. **Upgrading from 0.1.x:** a `CHANGEME` or whitespace-only `GOTO_SMS_ENCRYPTION_KEY` is now ignored (with a warning), so if you ran with one, set a real key, re-enter the client secret and reconnect. Plain-words startup errors; `authorize` can read `req.cookies` without a cast. |
| 0.1.2   | 2026-10-28 | Webhook ignores texts addressed to another number in the same GoTo account (subscriptions are account-wide), so a STOP or HELP sent to another app's number no longer opts out of, or replies from, this one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| 0.1.1   | 2026-10-28 | Webhook: answer GoTo's `OPTIONS` URL check on `/inbound/:secret` (200 when the secret matches, before webhook mode is on). Without it GoTo refused to create the channel and turning on webhook mode failed with a 502.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 0.1.0   | 2026-10-28 | First release of the Node package: OAuth with single-flight refresh, accounts/numbers discovery, `send`/`sendOrThrow` with dedupe and opt-out gates, inbound by webhook or polling, STOP/START/HELP, file/SQLite/custom stores, Express router and setup page, HTTP contract and conformance checklist.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
